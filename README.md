A small program that writes one haiku about debugging — three lines in the 5-7-5 syllable shape — to a text file.

## Run it

```sh
python3 main.py
```

The haiku is written to `entry.txt` under the output directory (`/output` by default, or `$OUTPUT_DIR` when set).
